# Curated Bash Resources

A comprehensive directory of authoritative documentation, manuals, guides, and recommended tutorials for mastering Bash scripting.

---

## Official Documentation & Reference Manuals

- [POSIX Utility Specifications (Shell & Utilities)](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/contents.html): The IEEE POSIX standard specification for portable shell syntax and utilities.
- [man7.org Linux Manual Pages](https://man7.org/linux/man-pages/): Authoritative online manual pages for system calls, commands, and formats maintained by Michael Kerrisk.
- [jq Manual](https://jqlang.github.io/jq/manual/): Official documentation for querying, slicing, filtering, and mapping JSON structures on the command line.
- [Git Documentation (git-scm.com)](https://git-scm.com/doc): Official reference for Git plumbing and porcelain commands used in deployment and version control scripts.

---

## Community Guides & Best Practices

- [Greg's Wiki: BashGuide](https://mywiki.wooledge.org/BashGuide): A clear, modern guide designed to teach Bash concepts correctly from the ground up.
- [Greg's Wiki: BashFAQ](https://mywiki.wooledge.org/BashFAQ): Practical solutions to common scripting questions and tricky edge cases.
- [Greg's Wiki: BashPitfalls](https://mywiki.wooledge.org/BashPitfalls): Deep dive into common shell programming mistakes, unquoted variables, and parsing errors.
- [ShellCheck Wiki](https://www.shellcheck.net/wiki/): Comprehensive explanations for all static analysis warnings generated by ShellCheck.
- [Google Shell Style Guide](https://google.github.io/styleguide/shellguide.html): Industry-standard conventions for authoring readable, maintainable shell scripts.

## Practice Environment

To practice shell scripting locally without third-party web compilers, use a standard terminal environment in:

- Linux / WSL (Ubuntu, Debian, Fedora)
- macOS Terminal (ensure Bash 4.4+ via Homebrew)
- Dedicated lab folder: `~/bash-lab`
